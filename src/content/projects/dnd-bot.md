A Discord bot for people who run a weekly D&D game and want less herding of players. The dungeon master configures it per server, and players use text commands to RSVP to the next session, vote to cancel when the group is short, and skip a week.

It also tracks registered players and keeps a simple shared inventory, with commands to add, remove and update items by quantity. It's written in Python and was deployed to production with GitHub Actions. The project is archived.
