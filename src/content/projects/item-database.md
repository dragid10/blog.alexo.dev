ItemDatabase is a work-in-progress tool for cataloging and tracking items around the house, built to be used with a barcode scanner: scan something to look it up or add it. It has a FastAPI backend, a desktop GUI, and a SQLite database, all in Python. It's still a work in progress, and the project is archived.
