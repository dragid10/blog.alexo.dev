This is the site you're on. It started life as a Ghost blog and now runs on Astro with the AstroPaper theme and TinaCMS, deployed on Vercel behind Cloudflare.

The home page is a link-in-bio hub, and from there you can find the blog, a speaking page, this projects section, an about page and a resume. Posts are plain Markdown files that I draft in Obsidian and publish with a small script and a pull request, and the project cards you're reading are Markdown too. It also has full-text search, an RSS feed, a dark mode and an installable offline-friendly PWA.
